# Синтетические микроданные БНС РК 2021–2024 — описательная аналитика

Результат 1 проекта: что лежит в наборе синтетических микроданных Бюро национальной статистики РК, как менялись ключевые показатели в 2021–2024 годах и насколько можно доверять разрезам.

Итог оформлен в трёх слайдах: [slides/Результат 1 — описательная аналитика.pdf](slides/). В репозитории лежат скрипты, промежуточные таблицы и графики, из которых собраны эти слайды.

> Сырые данные (≈4,4 ГБ CSV) в репозиторий **не входят**. Скрипты запускаются на локальной копии архива `synthetic_microdata_2021-2024_20260921`.

---

## Структура

```
scripts/     расчёты (DuckDB + pandas) и графики (matplotlib)
results/     агрегированные таблицы, на которые опираются слайды
charts/      PNG-графики со слайдов
slides/      HTML-исходники слайдов и итоговый PDF
```

| Скрипт | Что делает | Результаты |
|---|---|---|
| `scripts/profile.py` | Проходит по всем 236 таблицам из `MANIFEST.csv`: строки, столбцы, доля пустых ячеек, полностью пустые столбцы | `missing_by_table.csv` |
| `scripts/analysis.py` | Основные показатели по формам: 1-Т год, 2-Т, Т-001, Д-004, Д-008 | `t1god_*.csv`, `2t_*.csv`, `t001_*.csv`, `d004_summary.csv`, `d008_summary.csv` |
| `scripts/quarterly.py` | Квартальная зарплата по 1-Т кв., доля отказов Д-004, свод пропусков «форма × год» | `t1kv_wages_recomputed.csv`, `d004_refusal.csv`, `missing_form_year.csv` |
| `scripts/charts.py` | Четыре графика для слайдов | `charts/*.png` |
| `scripts/explore_*.py` | Разведочные запросы: какие коды показателей (KCP) и значения есть в формах | вывод в консоль |

## Как запустить

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

export DATA_DIR=/путь/к/synthetic_microdata_2021-2024_20260921
python scripts/profile.py      # ~десятки минут: читает все 72,6 млн строк
python scripts/analysis.py
python scripts/quarterly.py    # после profile.py
python scripts/charts.py
```

Все CSV читаются как текст (`all_varchar=true`), числа приводятся через `try_cast`, поэтому битые значения становятся `NULL`, а не ломают запрос.

## Слайд 1. Какие данные у нас есть

**236 таблиц, 72,6 млн строк, восемь форм за 2021–2024 годы.**

| Форма | Что измеряет | Строк | Единиц в год |
|---|---|---:|---|
| Т-001 | Рабочая сила, занятость | 1,89 млн | ~470 тыс. чел. 15+ |
| 2-Т | Зарплата работников | 7,33 млн | 560–640 тыс. чел. |
| 1-Т кв. | Предприятия, квартал | 24,5 млн | 29–32 тыс. предприятий |
| 1-Т год | Предприятия, год | 30,0 млн | 71–84 тыс.; в 2024 г. 52 |
| Д-004 | Доходы и расходы домохозяйств | 8,61 млн | 12 000 ДХ × 4 квартала |
| Д-008 | Состав домохозяйства | 169 тыс. | ~42 тыс. чел. |
| Д-002 | Самооценки | 95,5 тыс. | ~12 тыс. чел. |
| Д-006 | Жилищные условия | 46,7 тыс. | ~11,7 тыс. ДХ |

Формы связываются ключами: `NOMER` — домохозяйство (Д-002…Д-008), `ID` — предприятие (1-Т, 2-Т).

**Доля пустых ячеек** (`results/missing_form_year.csv`, график `charts/miss.png`): от 6–9% в 2-Т до 66–67% в Д-006. Пропуски в основном **структурные**: у таблиц с разрезами и переходами в анкете часть столбцов заполняется только для определённых строк. Это не потерянные ответы. В 1-Т год доля пропусков снижается с 58% до 34%: в 2024 году поменялась схема таблицы (30 столбцов вместо 16–19).

## Слайд 2. Динамика 2021–2024

**Медианная зарплата на предприятии выросла на 95%, доход домохозяйства на 68%, цены на 56%.**

График `charts/dyn.png` показывает три ряда, каждый приведён к индексу «1 кв. 2021 = 100»:

- **Зарплата на предприятии**: медиана по предприятиям показателя KCP `252101` (средняя начисленная зарплата) из 1-Т кв. Итог 4 кв. 2024: **195**. Ряд сильно колеблется: в 4 кв. 2023 года он доходит до 207.
- **Доход домохозяйства**: медиана денежного дохода ДХ за квартал из Д-004. Доход складывается из статей `GR1, GR2, GR4…GR21` таблицы `kv_vopr11`, в расчёт идут только ответившие ДХ (`REZ = 1`). Итог: **168**.
- **Цены (ИПЦ)**: накопленный индекс по официальным данным БНС (декабрь к декабрю). Итог: **156**.

Карточки справа:

| Показатель | Значение | Источник |
|---|---|---|
| Безработица, 15+ | 4,9% → 5,0% | `t001_summary.csv`. Безработный: `ZAN_RABOTA = 2` и `PSK_RABOTA = 1`; доля от (занятые + безработные) |
| Медианная зарплата работника | 141 → 236 тыс. тг (+67%) | `2t_summary.csv`, 2-Т, KCP `252101`, значения > 0 |
| Доля отказов в Д-004 | 0,3% → 2,4% | `d004_refusal.csv`: доля `REZ ≠ 1`. Каждый год растёт от 1-го к 4-му кварталу, в начале года сбрасывается |

Почему зарплата растёт на +95% в заголовке и на +67% в карточке: это разные меры. 1-Т кв. даёт медиану по **предприятиям**, где каждая фирма весит одинаково. 2-Т даёт медиану по **работникам**. На слайде показаны обе.

## Слайд 3. Распределения и ограничения

**Зарплаты сдвинулись вправо, безработица «постарела».**

- `charts/dist.png`: распределение зарплат работников по 2-Т за 2021 и 2024 годы, корзины по 25 тыс. тг (`2t_hist_*.csv`). Медиана сместилась со 141 до 236 тыс., хвост распределения стал толще.
- `charts/age.png`: безработица по возрастам по Т-001 (`t001_age.csv`). У молодёжи 15–34 она снизилась (25–34: 5,9% → 3,8%), у людей 35–64 выросла (45–54: 4,6% → 5,8%).

Что это говорит о самих синтетических данных:

- **Ж/М = 1,00.** В 2-Т медиана зарплаты женщин равна медиане мужчин (`fm_med` в `2t_summary.csv`). В реальной статистике разрыв есть, значит генератор его не сохранил.
- **Регионы: 201–247 тыс. тг.** Разброс медиан по областям узкий, Атырау на уровне Алматы (медианы по 1-Т год за 2024 г., `t1god_regions.csv`). Региональные различия в синтетике сглажены.
- **Вывод:** динамике во времени можно доверять, а связи между признаками (пол, регион, образование) стоит считать нижней границей настоящих эффектов.

Т-001 посчитана без весов, на ~470 тыс. респондентов в год.

## Ограничения и оговорки

- Данные **синтетические**. Их маргинальные распределения близки к реальным, но совместные связи ослаблены.
- Медианы по 1-Т считаются по строкам и предприятиям **без взвешивания** по численности: синтетическая численность слишком шумная, чтобы на неё опираться.
- **1-Т кв.:** в `results/t1kv_wages.csv` лежат исходные цифры, по которым строился слайд. Промежуточный запрос для них не сохранился. `scripts/quarterly.py` пересчитывает ряд заново (среднее по предприятию → медиана по предприятиям, `STKD = 1`) и пишет его в `t1kv_wages_recomputed.csv`. Направление и масштаб совпадают, отдельные кварталы расходятся: итог 192 против 195, в 4 кв. 2023 года 175 против 207. Пик в 4 кв. 2023 года лучше считать артефактом метода, а не фактом.
- ИПЦ взят из внешних данных БНС, в наборе его нет.

Все расчёты выполнены командой на синтетических микроданных БНС РК 2021–2024.
